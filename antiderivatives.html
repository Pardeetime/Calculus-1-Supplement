Each little segment shows the slope that a function F must have at that spot, given \( F'(x) = f(x) \). Any curve that follows the segments is an antiderivative, and there are infinitely many, stacked vertically. Drag the red point to choose one of them.

Drag the red point anywhere. Every curve in the family has the same shape, and only the vertical shift C changes.

Why “+ C”

Shifting a graph up or down doesn’t change any slopes. So if \( F' = f \), then \( (F + C)' = f \) too. By the Mean Value Theorem (Topic 4.2), those are the only antiderivatives. One extra fact, like a point the curve passes through, pins down C.

F is an antiderivative of f if \( F' = f \). The most general antiderivative is \( F(x) + C \). Every derivative rule, read backwards, is an antiderivative rule:

Constant multiples and sums work term by term. Always check by differentiating your answer. It takes seconds and catches almost every mistake.

Common mistakes

Forgetting + C. Using the power rule on \( x^{-1} \), which would divide by zero. Getting the sign wrong on \( \sin x \to -\cos x \). And trying to antidifferentiate products factor by factor: \( \int x\cdot x \ne \frac{x^2}{2}\cdot\frac{x^2}{2} \). Multiply out first.

Initial value problems

Find the general antiderivative, then use the given value to solve for C. With \( f'' \), antidifferentiate twice, and each step gets its own constant.
