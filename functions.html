What you just discovered

A graph is a function when every vertical line hits it at most once. A vertical line is one input x, and each hit is an output. More than one hit means one input produced several outputs.

A function is a rule that assigns to each input exactly one output. We write \( y = f(x) \) and read it “f of x.” The parentheses mean “apply f to,” not multiplication.

  • The domain is the set of inputs the function accepts.
  • The range is the set of outputs it actually produces.
Why calculus cares

Calculus studies how an output responds when you nudge the input. That question only makes sense if each input has one output to respond with.

Reading a function from its graph

On a graph, the input is horizontal and the output is vertical. The value \( f(a) \) is the height of the graph above (or below) \( x = a \). The domain is the graph’s shadow on the x-axis, and the range is its shadow on the y-axis.

Finding the domain from a formula

Unless the domain is stated, it’s every real number that doesn’t break the formula. In Calculus I only three things break a formula:

DivisionThe denominator can’t be 0\( \frac{1}{x-5} \): \( x \ne 5 \)

Evaluating: replace every x

To evaluate a function, replace every x with the input in parentheses. It works the same way when the input is a whole expression. Calculus uses \( f(a+h) \) constantly, starting with the very first definition of the derivative.

Common mistake

\( (a+h)^2 \ne a^2 + h^2 \). Squaring means multiplying the whole thing by itself: \( (a+h)(a+h) = a^2 + 2ah + h^2 \). Try it with numbers: \( (3+1)^2 = 16 \), but \( 3^2 + 1^2 = 10 \).

Piecewise functions

A piecewise function uses different formulas on different parts of the domain. To evaluate one, first decide which piece the input belongs to, then use only that formula.

\[ |x| = \begin{cases} -x, & x \lt 0 \\ \phantom{-}x, & x \ge 0 \end{cases} \]

Pay attention to \( \lt \) versus \( \le \). The boundary point belongs to exactly one piece.
