Picture the region under a curve as water in a tank, sloshed into hills and valleys. When it settles flat, what height does it reach? Move the gold line until the water above it (the hills) exactly fills the gaps below it (the valleys).

What you found

The level height makes a rectangle with the same area as the region under the curve. So height × width = area, and the level is \( \dfrac{\text{area}}{b - a} \). That height is the average value of f.

To average n sample values, add them and divide by n. Sample f at n evenly spaced points on \( [a, b] \), where \( \Delta x = \frac{b-a}{n} \):

\[ \frac{f(x_1) + \cdots + f(x_n)}{n} = \frac{1}{b - a}\sum_{i=1}^{n} f(x_i)\,\Delta x \;\xrightarrow{\;n\to\infty\;}\; \frac{1}{b - a}\int_a^b f(x)\,dx. \]
Average value
\[ f_{\text{avg}} = \frac{1}{b - a}\int_a^b f(x)\,dx \]
Mean Value Theorem for Integrals

If f is continuous on \( [a, b] \), there is some c in \( [a, b] \) with \( f(c) = f_{\text{avg}} \). The function actually reaches its average somewhere. It’s the IVT (Topic 1.7) applied to the average.

It all connects

The average value of a velocity is \( \frac{1}{b - a}\int_a^b v\,dt = \frac{\text{displacement}}{\text{time}} \), the ordinary average velocity from Topic 1.1. The course started by asking how to get from average rates to instantaneous ones, and it ends by going the other way.
