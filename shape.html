TestStatement
Increasing/Decreasing\( f' \gt 0 \) on an interval ⟹ f increasing; \( f' \lt 0 \) ⟹ decreasing.
First Derivative TestAt a critical number c: \( f' \) changes + to − ⟹ local max; − to + ⟹ local min; no sign change ⟹ neither.
Concavity\( f'' \gt 0 \) ⟹ concave up (bends like ∪, slopes increasing); \( f'' \lt 0 \) ⟹ concave down (∩).
Inflection pointA point on the graph where concavity changes. It’s usually where \( f'' = 0 \) or is undefined, and changes sign.
Second Derivative TestIf \( f'(c) = 0 \): \( f''(c) \gt 0 \) ⟹ local min (cup); \( f''(c) \lt 0 \) ⟹ local max (cap); \( f''(c) = 0 \) ⟹ inconclusive.
Common mistakes

\( f''(c) = 0 \) does not automatically mean an inflection point: \( x^4 \) has \( f''(0) = 0 \) but is concave up on both sides. Always check for a sign change. Also, when the Second Derivative Test gives 0, go back to the First Derivative Test. Don’t conclude “neither.”
